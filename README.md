## 🤯 What Is This?

> **Your phone is now a dev machine.**

Codex AI Coding Agent - OnDev (package `ai.chatbot`) is an AI coding app for Android based on the open-source Codex project. Generate, edit, and explain code across multiple programming languages, prototype websites and automation scripts, generate project images, and manage projects from your phone or tablet — with local-first workflows and Linux-on-Android integration for developers, makers, and AI enthusiasts.

## 🧠 TL;DR Privacy

> **Your code stays yours. Know what leaves your device before you build.**

Coding prompts and project content you submit are sent to the AI service only to generate the requested assistance. Many features run locally on your device. LonLes Ltd does not operate accounts or store your code on its own servers. Read the [Privacy Policy](https://lonles-ltd.github.io/ai-chatbot-privacy/).

## ⚡ What You Get

- 🤖 AI-powered coding assistant: generate, edit, and explain code
- 🌐 Build Android apps, websites, prototypes, automation scripts
- 💻 Multi-language support for software, web, and mobile work
- 🐧 Linux-on-Android integration and local-first workflows
- 🎨 Image generation for projects and creative work
- 🧹 Find duplicate photos and large files on your device
- 📋 Daily summaries and productivity suggestions
- 🔧 Optional Shizuku support for advanced Android automation
- 📱 Fast interface optimised for phones and tablets

## 🔐 Privacy First

> **Local-first where possible. Transparent where cloud is involved.**

On-device features (Linux workflows, duplicate-photo / large-file finder, local project work) process your data on your device. When you ask the AI assistant for help, your prompts and relevant code are transmitted to the AI service solely to produce the answer. Do not paste passwords, API keys, or other secrets into the assistant.

[Read the full Privacy Policy →](https://lonles-ltd.github.io/ai-chatbot-privacy/)
